# UI Guidelines

Design goals:

- Professional
- Clean
- Minimal
- Fast

Every screen should help answer:
'Should I pursue this property?'

Prioritize clarity over decoration.

## Authoritative Visual Specification

`docs/DESIGN_SYSTEM.md` is the authoritative visual specification for
Formetrix — colors, typography, spacing, radii, shadows, motion, and
component-level patterns (buttons, cards, badges, progress indicators,
navigation, data display, accessibility, and dashboard interaction
patterns). Where this file states a goal, `DESIGN_SYSTEM.md` states how
that goal is implemented in code. Applied first to
`/internal/project-dashboard` (FM-0026); apply the same system when
building product-facing screens rather than inventing a parallel one.
